# CAHIER DES CHARGES
## Projet : Gestion de maintenance industrielle

### 1. Présentation du projet

Le projet consiste à concevoir un classeur automatisé de gestion de maintenance industrielle, compatible avec Microsoft Excel et LibreOffice Calc.

Ce classeur permettra d'organiser les informations relatives aux équipements, aux interventions, aux pannes et aux opérations de maintenance.

### 2. Objectif général

Développer un outil de gestion interactif permettant de faciliter la saisie, le suivi, l'analyse et l'exploitation des données de maintenance industrielle.

### 3. Objectifs spécifiques

- Créer des menus déroulants simples et dépendants.
- Automatiser la saisie à l'aide de formules.
- Développer des macros pour automatiser certaines opérations.
- Enregistrer et consulter l'historique des interventions.
- Générer des statistiques de maintenance.
- Concevoir un tableau de bord interactif.
- Assurer la compatibilité entre Excel et LibreOffice Calc.

### 4. Fonctionnalités attendues

**4.1. Gestion des équipements**
- Identification des équipements.
- Classification par service.
- Consultation des caractéristiques.

**4.2. Gestion des interventions**
- Formulaire de saisie.
- Menus déroulants dépendants.
- Identification des pannes.
- Enregistrement des interventions.
- Consultation de l'historique.

**4.3. Automatisation**
- Calculs automatiques.
- Boutons de commande.
- Macros VBA.
- Macros LibreOffice Basic.

**4.4. Tableau de bord**
- Nombre d'interventions.
- Répartition des pannes.
- Équipements les plus sollicités.
- Indicateurs de maintenance.
- Graphiques dynamiques.

### 5. Environnement technique

| Composant | Technologie |
|---|---|
| Système d'exploitation | Ubuntu/Linux |
| Tableur 1 | LibreOffice Calc |
| Tableur 2 | Microsoft Excel |
| Formules | Fonctions Calc et Excel |
| Macros Excel | VBA |
| Macros LibreOffice | LibreOffice Basic |
| Gestion de versions | Git |
| Hébergement du projet | GitHub |

### 6. Architecture du classeur

Le classeur sera organisé en cinq feuilles principales :

1. ACCUEIL
2. LISTES
3. SAISIE
4. HISTORIQUE
5. TABLEAU_BORD

### 7. Contraintes du projet

- Utilisation possible sans connexion Internet.
- Interface simple et professionnelle.
- Protection contre les erreurs de saisie.
- Conservation des données.
- Compatibilité testée entre Excel et Calc.
- Documentation des macros et des formules.

### 8. Résultats attendus

À la fin du projet, nous devons disposer :

- D'un classeur fonctionnel sous LibreOffice Calc.
- D'un classeur fonctionnel sous Microsoft Excel.
- De menus déroulants dépendants opérationnels.
- De macros adaptées aux deux logiciels.
- D'un système d'historisation.
- D'un tableau de bord interactif.
- D'une documentation technique et utilisateur.

### 9. Critères de validation

Le projet sera considéré comme terminé lorsque :

- Les menus déroulants fonctionnent correctement.
- Les sous-menus se mettent à jour selon les sélections précédentes.
- Les formules produisent les résultats attendus.
- Les macros exécutent correctement leurs fonctions.
- Les interventions sont enregistrées et consultables.
- Les tableaux de bord affichent des statistiques cohérentes.
- Les deux versions ont passé les tests de compatibilité.

### 10. Évolution du projet

Le projet sera développé progressivement. Chaque fonctionnalité sera testée, documentée et enregistrée dans GitHub avant de passer à la suivante.
